# Low‑code веб‑платформа для сравнения эффективности моделей обнаружения мошеннических транзакций

Платформа, позволяющая аналитикам безопасности и риск-менеджерам без навыков программирования быстро настраивать синтетические данные, сравнивать несколько моделей машинного обучения по ключевым метрикам и принимать обоснованные решения о внедрении алгоритмов в реальную систему фрод-мониторинга.

## Ключевые возможности

- **Генерация синтетических данных**  
  Создание подвыборок от 100 до 5000 строк с заданной долей мошеннических транзакций (по умолчанию 5%).
- **Стресс-сценарии**  
  Четыре предустановленных сценария: экстремальный дисбаланс (0.1% фрода), сдвиг суммы у мошенников, маскировка под нормальное поведение, всплеск частоты операций.
- **6 предобученных моделей**  
  Логистическая регрессия, два варианта случайного леса, два варианта CatBoost, Isolation Forest. Модели загружаются один раз при старте и не требуют переобучения.
- **Два режима оценки**  
  Автоматический расчёт метрик в классическом режиме (стандартные параметры) и в выбранном стресс-сценарии с вычислением просадки каждой метрики.
- **Бизнес-стоимость ошибок**  
  Настраиваемая cost matrix: веса False Positive и False Negative задаются через слайдеры, итоговая стоимость ошибок добавляется в таблицу результатов.
- **Интерактивные графики (Plotly)**  
  - ROC-кривая с регулируемым порогом для любой модели  
  - Тепловая карта confusion matrix  
  - График «Метрика vs порог» (Precision, Recall, F1)  
  - Bar chart сравнения всех моделей по выбранной метрике  
  - Feature importance для древовидных моделей  
  - SHAP summary plot (опционально)
- **Работа с пользовательскими данными**  
  Загрузка CSV, автоматическая валидация столбцов и типов данных, интерактивное редактирование ячеек через `st.data_editor`, оценка на загруженных данных.
- **Low‑code интерфейс**  
  Все действия выполняются через веб-интерфейс Streamlit — не требуется писать код. Элементы управления снабжены подсказками и интуитивно понятны.

## Установка и локальный запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/yourteam/fraud-model-comparator.git
cd fraud-model-comparator

# Создайте и активируйте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
streamlit run app.py
```

# Руководство пользователя

**1. Боковая панель.**
- Выберите размер синтетической выборки (100–5000 строк).
- Выберите стресс-сценарий или оставьте «Классический» (5% фрода).
- При необходимости настройте веса False Positive и False Negative в cost matrix.
- Нажмите кнопку «Сравнить модели».
**2. Таблицы результатов.**
- Вкладка «Метрики»: для каждой модели отображаются Accuracy, Precision, Recall, F1, ROC‑AUC и бизнес-стоимость в классическом и стресс‑режимах, а также просадка.
- Вкладка «Детальный анализ»: выберите модель из выпадающего списка для просмотра графиков (ROC, confusion matrix, feature importance и др.).
**3. Загрузка своих данных.**
- Воспользуйтесь кнопкой «Загрузить CSV» в боковой панели.
- Система проверит наличие всех необходимых столбцов и типы данных. При ошибках вы получите понятное сообщение.
- После успешной загрузки можно отредактировать ячейки в таблице и нажать «Оценить на пользовательских данных» — модели выполнят предсказания без переобучения.
**4. Графики и экспорт**
- Все графики интерактивны: можно зумировать, выбирать порог, переключать модели.
- Результаты сравнения можно скачать в CSV (кнопка «Скачать результаты»).
