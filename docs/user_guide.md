# Руководство по загрузке данных

## Формат CSV
- Расширение: `.csv`
- Разделитель: запятая
- Кодировка: UTF-8

## Список обязательных колонок
Все признаки, необходимые для корректной работы моделей, подробно описаны в [Словаре данных](data_dictionary.md).

Обратите внимание: файл должен содержать **все** колонки из таблиц «Статичные признаки клиента», «Динамические признаки транзакции» и «Сигнальные признаки», а также целевую переменную `is_fraud`.

## Пример строки (для справки)
Вы можете сгенерировать пример через само приложение (кнопка «Запустить анализ» без загрузки CSV) и затем скачать его.

## Ошибки и их решение
- **«Отсутствуют колонки»** → сравните свой файл со списком в [Словаре данных](data_dictionary.md
- **Неверный тип** → убедитесь, что все значени соответствуют документации.
- **Некорректное расширение** → сохраните файл как `.csv`.
